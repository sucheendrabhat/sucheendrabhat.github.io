## Polyhedral Representation

In polyhedral compilation, loop nests with static bounds are modeled as integer polyhedra bounded by linear inequalities.

$$\mathcal{D} = \{ \vec{i} \in \mathbb{Z}^n \mid A \vec{i} + \vec{b} \ge \vec{0} \}$$

## Key Concepts

- **Iteration Domain**: The set of integer vectors generated by loop induction variables.
- **Access Relations**: Affine maps from iteration domain to memory locations.
- **Schedule**: Affine function mapping iterations to logical execution time.
